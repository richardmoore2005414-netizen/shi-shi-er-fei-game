# 似是而非 · True or False: Myth Buster

快节奏迷思辨識遊戲，打破日常迷思，發現驚人真相。

## 線上玩

開啟 **[GitHub Pages](https://richardmoore2005414-netizen.github.io/shi-shi-er-fei-game/)**  （若尚未啟用，請到 Repo → Settings → Pages → Source 選 `main` / root）

或直接開啟 `index.html`。

## 核心玩法

1. **True / False 速答**（每題 10 秒）  
   - 答對 +10 分，答錯或超時 -10 分（最低 0 分）
2. **進階四選一**（僅當你成功識破 False 迷思時觸發，15 秒）  
   - 答對再 +10（本題最高 +20）  
   - 答錯不扣分
3. **排行榜**：總分 → 用時 → 準確率（儲存於瀏覽器 localStorage）

## 題庫

內含 12 題（動物、人體健康、食物、太空、歷史），每局隨機抽 10 題。

## 技術

純前端 HTML / CSS / JS，無依賴，可直接部署 GitHub Pages 或任何靜態主機。
